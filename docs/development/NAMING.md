# Project Naming

## Repository and workspace

- Folder and repository workspace: `pccooler-project`

## Current application compatibility names

- Product: `PCCOOLER-LCD Control`
- Command: `pccooler-lcd-control`
- Python import package: `pccooler_lcd`
- systemd user unit: `pccooler-lcd-control.service`

The compatibility names are intentionally unchanged in this reorganization. Renaming the Python package or CLI should be handled later as a dedicated migration because it affects imports, packaging, launchers, services, and user configuration.
